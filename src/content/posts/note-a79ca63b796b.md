## 七、矩阵与多行公式

**矩阵**

latex

```latex
$$
\begin{matrix}
1 & 2 \\
3 & 4
\end{matrix}
$$
```



括号类型替换 `matrix`：

- `pmatrix` → ( )
- `bmatrix` → [ ]
- `Bmatrix` → { }
- `vmatrix` → | |
- `Vmatrix` → ‖ ‖

**多行公式对齐**

latex

```latex
$$
\begin{aligned}
a &= b + c \\
  &= d + e
\end{aligned}
$$
```



**分段函数**

latex

```latex
$$
f(x) = 
\begin{cases}
x^2, & x \ge 0 \\
0,  & x < 0
\end{cases}
$$
```
